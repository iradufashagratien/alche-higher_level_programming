# python-input_output

This project covers reading and writing files, and serializing/
deserializing Python objects using JSON, in Python 3.

## Tasks
- `0-read_file.py`: read and print a text file
- `1-write_file.py`: write a string to a text file
- `2-append_write.py`: append a string to a text file
- `3-to_json_string.py`: return the JSON representation of an object
- `4-from_json_string.py`: return an object from a JSON string
- `5-save_to_json_file.py`: write an object to a file as JSON
- `6-load_from_json_file.py`: create an object from a JSON file
- `7-add_item.py`: append CLI args to a JSON list file
- `8-class_to_json.py`: dictionary description of a simple object
- `9-student.py`: Student class with to_json
- `10-student.py`: Student class with filtered to_json
- `11-student.py`: Student class with reload_from_json
- `12-pascal_triangle.py`: build Pascal's Triangle
