# JavaScript Web Scraping


This project is about reading and writing files with Node.js and scraping data from the web using the request module.

## Requirements


* Ubuntu 14.04 LTS, Node.js 10
* Code follows semistandard style
* All files are executable and end with a new line
* The first line of every file is `#!/usr/bin/node`
* No use of `var`

## Files


* `0-readme.js` reads and prints the content of a file
* `1-writeme.js` writes a string to a file
* `2-statuscode.js` prints the status code of a GET request
* `3-starwars_title.js` prints the title of a Star Wars movie by ID
* `4-starwars_count.js` counts the movies where Wedge Antilles (ID 18) appears
* `5-request_store.js` saves the body of a webpage into a file
* `6-completed_tasks.js` counts completed tasks per user ID
