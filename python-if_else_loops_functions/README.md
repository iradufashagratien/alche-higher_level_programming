# python-if_else_loops_functions

Holberton/ALX School - Higher Level Programming.

This project covers Python basics: `if`/`else` statements, loops
(`for`, `while`), and functions. Each task is a standalone script or
module solving a specific exercise, run on Ubuntu 20.04 with
Python 3.8.5 and validated against `pycodestyle` 2.7.x.

## Files

| File | Description |
|---|---|
| `0-positive_or_negative.py` | Prints whether a random number is positive, negative, or zero |
| `1-last_digit.py` | Prints the last digit of a random number and describes it |
| `2-print_alphabet.py` | Prints the lowercase alphabet |
| `3-print_alphabt.py` | Prints the lowercase alphabet, excluding `q` and `e` |
| `4-print_hexa.py` | Prints numbers 0-98 in decimal and hexadecimal |
| `5-print_comb2.py` | Prints numbers 00 to 99 |
| `6-print_comb3.py` | Prints all unique two-digit combinations |
| `7-islower.py` | Checks if a character is lowercase |
| `8-uppercase.py` | Prints a string in uppercase |
| `9-print_last_digit.py` | Prints and returns the last digit of a number |
| `10-add.py` | Adds two integers |
| `11-pow.py` | Computes a to the power of b |
| `12-fizzbuzz.py` | Prints the FizzBuzz sequence from 1 to 100 |
