# python-import_modules

Holberton/ALX School - Higher Level Programming.

This project covers importing functions, variables, and compiled
modules in Python, plus reading command line arguments with
sys.argv. Run on Ubuntu 20.04 with Python 3.8.5, checked against
pycodestyle 2.7.x.

## Files

| File | Description |
|---|---|
| `0-add.py` | Imports and uses `add` from `add_0.py` |
| `1-calculation.py` | Imports and uses all four functions from `calculator_1.py` |
| `2-args.py` | Prints the number and list of arguments passed to the script |
| `3-infinite_add.py` | Adds up all arguments given on the command line |
| `4-hidden_discovery.py` | Lists the public names defined in `hidden_4.pyc` |
| `5-variable_load.py` | Imports and prints the variable `a` from `variable_load_5.py` |
